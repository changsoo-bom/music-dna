# 디자인 레퍼런스

토큰의 **값**과 **그 값인 이유**. 작성 규칙은 `.claude/rules/styling.md`에 있다.
구현된 화면 원본은 `design/prototype.html` (단일 HTML, 의존성 없음).

디자인 언어는 Mastercard 계열 — 따뜻한 크림 캔버스, 필과 원, 잉크 블랙 CTA, 단일 폰트 시스템.

### 이 조합을 임의로 바꾸지 말 것

`#F3F0EE` 표면 기준으로 검증을 통과한 조합이다. 검증기는
`dataviz` 스킬의 `scripts/validate_palette.js`.

```
명도 대역   PASS  (전 5색 OKLCH L 0.43–0.77)
채도 하한   PASS  (전 5색 chroma ≥ 0.1)
색각 대비   PASS  (인접 최악 #B4521E↔#00897C  deutan ΔE 12.1 · tritan 17.7)
정상시 대비 PASS  (인접 최악 #7A3E9E↔#C0405B  ΔE 17.9)
표면 대비   PASS  (전 5색 ≥ 3:1)
```

**배열 순서 자체가 검증 단위다.** 인접한 두 색의 구별 가능성을 재기 때문에,
슬롯 순서를 섞으면 검증이 다시 필요하다. 범례와 스택 밴드는 이 순서대로 그린다.

**6색으로 늘리지 말 것.** 클레이(`#B4521E`)와 올리브 계열은 적록색약에서 ΔE 0.6까지
붙는다. 크림 배경에서 6번째 색을 넣으면 채도 하한이나 색각 대비 중 하나가 반드시 깨진다.
장르가 6개 이상이면 상위 5개 + "기타"로 접는다.

색을 바꿔야 하면 검증기를 다시 돌리고 이 표를 갱신한다:

```bash
node <dataviz-skill>/scripts/validate_palette.js "<hex,hex,...>" --mode light --surface "#F3F0EE"
```

## 반경

| 토큰 | 값 | 용도 |
|---|---|---|
| `rounded-btn` | 20px | 주·보조 CTA |
| `rounded-stadium` | 40px | 히어로 프레임, 큰 섹션 컨테이너, 푸터 상단 |
| `rounded-pill` | 999px | 네비, 칩, 장르 밴드, 캐러셀 카드, 스탯, 툴팁 |
| `rounded-full` | 50% | 원형 초상, 위성 버튼, 아이콘 버튼, 범례 점 |

**8~16px 구간을 만들지 않는다.** 이 시스템이 "정밀하거나(≤6px) 부드럽거나(20px+)"
둘 중 하나로만 읽히는 이유가 중간값이 없기 때문이다.

## 그림자

| 토큰 | 값 | 용도 |
|---|---|---|
| `shadow-lift` | `0 4px 24px rgb(0 0 0 / .04)` | 네비 필, 스탯 필, 칩, 위성 버튼 |
| `shadow-float` | `0 24px 48px rgb(0 0 0 / .08)` | 스타디움 프레임, 필 카드, 툴팁 |

방향성 광원이 아니라 **대기 쿠션**이다. 퍼짐이 넓고 불투명도가 낮다.
기능적 구분선은 그림자 대신 `--hair` 1px 라인을 쓴다.

## 타이포

단일 폰트 시스템. 대비는 크기·굵기·자간에서 나오지, 두 번째 서체에서 나오지 않는다.

| 역할 | 폰트 | 로딩 |
|---|---|---|
| 라틴 | **Sofia Sans** (가변, `--font-sofia`) | `next/font/google` |
| 한글 | **Pretendard** (정적 400·500·700, `--font-kr`) | `next/font/local`, `src/fonts/` |

원본 시스템의 MarkForMC는 유료 라이선스라 Sofia Sans로 대체했다 (Mastercard의 폴백
스택에도 들어 있는 서체). 한글은 Pretendard 정적 웨이트 3종을 저장소에 번들한다 —
OFL 1.1, 고지는 `src/fonts/README.md`.

### 450 이 한글에서 어떻게 렌더되나

Pretendard는 가변 파일이 없어 450 웨이트가 존재하지 않는다.
CSS 폰트 매칭은 400–500 구간에서 **요청값 이하를 먼저 찾으므로** `font-weight: 450` 은
Regular(400) 파일로 떨어진다. 즉 라틴은 실제 450, 한글은 400으로 렌더된다.

**이건 버그가 아니라 의도된 결과다.** Pretendard 400 은 획이 상대적으로 굵어서
Sofia Sans 450 옆에서 무게가 맞는다. Medium(500)을 450으로 선언해 끌어오면 한글만
눈에 띄게 무거워진다 — 하지 말 것.

| 역할 | 크기 | 굵기 | 자간 |
|---|---|---|---|
| H1 (히어로) | 64px | 500 | -2% |
| H2 (섹션) | 36px | 500 | -2% |
| H3 (카드) | 24px | 500 | -2% |
| 아이브로우 | 14px | 700 | +4%, 대문자 |
| 본문 | 16px | **450** | 기본 |
| 버튼·네비 | 16px | 500 | -2% |

**450은 이 시스템의 서명이다.** 400으로 낮추면 본문이 얇아지면서 톤이 통째로 바뀐다.
대문자 변환은 14px 아이브로우에만 허용한다.

## 구조 규칙

- **아이브로우 = 점 + 대문자 라벨.** 점을 빼지 않는다. 섹션 카테고리 신호이자 아이덴티티다
- **위성 CTA**: 원형 초상의 45° 지점(`left/top: 84%` + `translate(-50%,-50%)`)에 도킹.
  크기와 무관하게 40~50% 돌출한다. 필 카드에서는 남극(`bottom: -28px`)에 붙인다
- **궤도 호**: 원형 초상 섹션에서만. 필 섹션·푸터에는 그리지 않는다.
  비대칭 배치일 때만 성립하므로 1023px 이하에서 숨긴다
- **동심 궤도 호**: 위 규칙의 예외이자 확장. 원형 초상을 **감싸는 동심원**으로 그린다.
  좁은 화면에서 숨기지 않는다 — 숨기는 이유였던 "비대칭 배치가 무너진다" 가
  동심원에는 해당하지 않는다. 현재 사용처: 추천 카드(`RecommendList`)
- **호의 길이로 값을 그리지 않는다.** 한 번 시도했다가 되돌렸다.
  원 둘레를 부분만 채운 그림은 **재생 진행률로 읽힌다** — 위성 재생 버튼이
  바로 옆 45° 에 도킹하니 더 그렇다. 없는 기능을 광고하는 셈이라 전부 한 바퀴로 맞췄다.
  값은 글로 말한다
- **단일 테마.** 섹션이 중간에 반전되지 않는다. 푸터의 잉크 블랙은 시스템이 규정한
  세 번째 표면이지 다크 모드가 아니다
